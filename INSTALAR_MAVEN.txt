║                                                                           ║
║                   COMO INSTALAR O APACHE MAVEN                           ║
║                                                                           ║
╚═══════════════════════════════════════════════════════════════════════════╝

O Maven é necessário para compilar e executar o backend Java do sistema.

📥 PASSO 1: BAIXAR O MAVEN
═══════════════════════════════════════════════════════════════════════════

1. Acesse: https://maven.apache.org/download.cgi

2. Baixe o arquivo ZIP (Binary):
   apache-maven-3.9.6-bin.zip
   (ou versão mais recente)

3. Tamanho aproximado: 9 MB


📦 PASSO 2: EXTRAIR O ARQUIVO
═══════════════════════════════════════════════════════════════════════════

1. Extraia o arquivo ZIP baixado

2. Mova a pasta extraída para:
   C:\apache-maven-3.9.6

   A estrutura deve ficar:
   C:\apache-maven-3.9.6\
   ├── bin\
   │   ├── mvn.cmd
   │   └── mvn.bat
   ├── conf\
   └── lib\


🔧 PASSO 3: ADICIONAR AO PATH
═══════════════════════════════════════════════════════════════════════════

Windows 11/10:

1. Clique com botão direito em "Este Computador"
   → Propriedades

2. Clique em "Configurações avançadas do sistema"

3. Clique em "Variáveis de Ambiente"

4. Em "Variáveis do sistema", encontre a variável "Path"

5. Clique em "Editar"

6. Clique em "Novo"

7. Adicione o caminho:
   C:\apache-maven-3.9.6\bin

8. Clique em "OK" em todas as janelas


✅ PASSO 4: VERIFICAR INSTALAÇÃO
═══════════════════════════════════════════════════════════════════════════

1. IMPORTANTE: Feche TODAS as janelas do Prompt de Comando

2. Abra um NOVO Prompt de Comando

3. Digite:
   mvn -version

4. Você deve ver algo como:
   Apache Maven 3.9.6
   Maven home: C:\apache-maven-3.9.6
   Java version: 1.8.0_341


❌ SE NÃO FUNCIONAR
═══════════════════════════════════════════════════════════════════════════

ERRO: "mvn não é reconhecido como comando interno ou externo"

SOLUÇÃO:
1. Verifique se o PATH está correto:
   echo %PATH%

2. Procure por: C:\apache-maven-3.9.6\bin

3. Se não aparecer:
   - Feche TODAS as janelas do CMD
   - Adicione ao PATH novamente (Passo 3)
   - Abra NOVO CMD


💡 DICA: INSTALAÇÃO RÁPIDA VIA CHOCOLATEY (OPCIONAL)
═══════════════════════════════════════════════════════════════════════════

Se você tem o Chocolatey instalado, pode instalar Maven rapidamente:

1. Abra PowerShell como Administrador

2. Execute:
   choco install maven

3. Maven será instalado e configurado automaticamente

📞 APÓS INSTALAR

2. Todos os requisitos devem estar OK

3. Inicie o sistema:
   INICIAR_SISTEMA_HIBRIDO.bat
