                     ⚡ COMANDOS ESSENCIAIS
========================================================================

NO TERMINAL DO VS CODE (pasta backend):

1️⃣  Compilar:
    mvn clean package -DskipTests

2️⃣  Executar backend:
    mvn spring-boot:run

3️⃣  Novo terminal, voltar pra raiz:
    cd ..

4️⃣  Executar frontend:
    python app.py

5️⃣  Acessar no navegador:
    http://localhost:5000

========================================================================
                     🔍 O QUE VOCÊ TEM AQUI
========================================================================

✓ Backend em Java Spring Boot
  └─> Gera documentos mais rápido que Python
  └─> Usa POI-TL (equivalente ao python-docx)
  └─> Banco de dados H2 embutido
  └─> API REST na porta 8080

✓ Frontend em Python Flask
  └─> Interface web que você já conhece
  └─> Conecta automaticamente ao backend Java
  └─> Continua funcionando mesmo se Java falhar
  └─> Servidor web na porta 5000

✓ Integração automática
  └─> Python tenta usar Java primeiro
  └─> Se Java não responder, usa Python
  └─> Transparente para o usuário
