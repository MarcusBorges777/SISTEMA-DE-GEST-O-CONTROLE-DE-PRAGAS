🚀 INSTALACAO EM 2 PASSOS
═══════════════════════════════════════════════════════════════════════════

PASSO 1: Instalar Maven LOCALMENTE (sem precisar de admin!)
────────────────────────────────────────────────────────────────────────────

Execute este arquivo:

  → INSTALAR_MAVEN_LOCAL.bat

Este script vai:
  • Baixar Maven 3.9.6 (9 MB)
  • Instalar na pasta "tools" deste projeto
  • Criar scripts de atalho
  • NAO precisa de permissoes de administrador!
  • NAO mexe com o PATH do Windows

Tempo estimado: 2-3 minutos


PASSO 2: Iniciar o sistema
────────────────────────────────────────────────────────────────────────────

Execute este arquivo:

  → INICIAR_SISTEMA_HIBRIDO.bat

O sistema vai:
  • Compilar o backend Java automaticamente
  • Iniciar backend na porta 8080
  • Iniciar frontend na porta 5000
  • Abrir o navegador

Tempo na primeira vez: 3-5 minutos (baixa dependencias)
Tempo nas proximas vezes: 30 segundos


✅ PRONTO!
═══════════════════════════════════════════════════════════════════════════

Acesse no navegador:

  Interface Web:  http://localhost:5000
  API Java:       http://localhost:8080/api
  Banco H2:       http://localhost:8080/api/h2-console


🔄 OPCAO ALTERNATIVA: Usar so Python
═══════════════════════════════════════════════════════════════════════════

Se nao quiser instalar Maven agora, pode usar o modo legado:

  → INICIAR_SISTEMA.bat

Este modo:
  • Funciona 100% em Python
  • Mais lento na geracao de documentos
  • Nao precisa de Java/Maven

❓ PERGUNTAS FREQUENTES
═══════════════════════════════════════════════════════════════════════════

P: Por que Maven local e nao global?
R: Maven local nao precisa de permissoes de administrador e funciona
   isolado neste projeto.

P: Posso usar Maven global se ja tiver instalado?
R: Sim! O sistema detecta automaticamente Maven global ou local.

P: Preciso ter Java instalado?
R: Sim, Java e obrigatorio para o modo hibrido. Mas voce ja tem instalado!

P: E se Maven local falhar?
R: Use o modo legado (INICIAR_SISTEMA.bat) que funciona so com Python.

P: Posso remover Maven depois?
R: Sim, basta deletar a pasta "tools". O sistema volta a usar Python.
