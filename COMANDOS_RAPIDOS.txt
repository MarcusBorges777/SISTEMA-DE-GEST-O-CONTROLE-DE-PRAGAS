========================================================================
                      COMANDOS RÁPIDOS
========================================================================

                    NO TERMINAL DO VS CODE
========================================================================

1. COMPILAR O BACKEND:
   mvn clean package -DskipTests

2. EXECUTAR O BACKEND:
   mvn spring-boot:run

3. VOLTAR PARA PASTA RAIZ (abrir novo terminal):
   cd ..

4. EXECUTAR O FRONTEND:
   python app.py

========================================================================
                    ACESSAR O SISTEMA
========================================================================

Frontend (interface web):
http://localhost:5000

Backend (API REST):
http://localhost:8080/api

Banco de dados H2 Console:
http://localhost:8080/api/h2-console

========================================================================
                    TESTAR SE ESTÁ FUNCIONANDO
========================================================================

1. Backend rodando?
   Acesse: http://localhost:8080/api/health
   Deve retornar: {"status":"UP"}

2. Frontend rodando?
   Acesse: http://localhost:5000
   Deve abrir a página inicial

3. Python conectando ao Java?
   Veja os logs do Flask
   Deve aparecer: "Java backend disponível"
