O comando "mvn" não funciona no PowerShell porque Maven não está no PATH.
MAS já criei scripts PowerShell que funcionam!

========================================================================
                     ✅ SOLUÇÃO RÁPIDA
========================================================================

No terminal do VS Code (pasta backend), execute:

1️⃣  COMPILAR:
    .\compilar.ps1

2️⃣  EXECUTAR:
    .\iniciar.ps1

3️⃣  NOVO TERMINAL, voltar pra raiz:
    cd ..

4️⃣  FRONTEND:
    python app.py

5️⃣  ACESSAR:
    http://localhost:5000

========================================================================
                     📝 DETALHES
========================================================================

Os scripts PowerShell (.ps1) estão em:
  • backend\compilar.ps1  -> Compila o projeto
  • backend\iniciar.ps1   -> Executa o servidor

Eles usam o Maven local que já está instalado em:
  tools\apache-maven-3.9.12\bin\mvn.cmd

========================================================================
                     ⚠️ SE DER ERRO DE PERMISSÃO
========================================================================

Se aparecer erro ao executar scripts .ps1, execute UMA VEZ:

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

Depois tente novamente: .\compilar.ps1

========================================================================
                     💡 ALTERNATIVAS
========================================================================

Se os scripts PowerShell não funcionarem, você tem outras opções:

OPÇÃO A: Interface do VS Code
  1. Ctrl + Shift + P
  2. "Java: Build Workspace"
  3. "Spring Boot Dashboard: Run"

OPÇÃO B: Usar CMD ao invés de PowerShell
  1. No terminal, clique na seta ▼
  2. Selecione "Command Prompt"
  3. Execute: ..\tools\apache-maven-3.9.12\bin\mvn clean package

OPÇÃO C: Instalar Maven no PATH
  Execute como admin: INSTALAR_MAVEN_DEFINITIVO.bat
