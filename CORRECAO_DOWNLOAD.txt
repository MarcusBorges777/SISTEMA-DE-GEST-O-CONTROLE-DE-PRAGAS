===========================================
CORREÇÃO: Botão de Download/Geração de Documentos
===========================================

PROBLEMA IDENTIFICADO:
- Botão "Gerar Documento Inteligente" não estava funcionando
- Laudos não estavam sendo gerados

CAUSA RAIZ:
O formulário de geração estava tentando acessar elementos HTML antigos que não existem mais:
- select-cliente-doc (antigo select de clientes)
- select-modelo (antigo select de modelos)

Com o novo sistema de cards, esses elementos foram substituídos por:
- cliente-id-selecionado (input hidden)
- modelo-selecionado (input hidden)

===========================================
FLUXO CORRETO AGORA:
===========================================

1. Usuário seleciona CLIENTE (card) → preenche 'cliente-id-selecionado'
2. Usuário seleciona CATEGORIA (Laudos/Recibos/Orçamentos)
3. Área expansível mostra cards de modelos daquela categoria
4. Usuário clica em um MODELO → preenche 'modelo-selecionado'
5. Sistema chama carregarVariaveisModeloNovo(arquivo)
6. Campos de variáveis aparecem baseados no tipo
7. Usuário preenche campos e clica "Gerar Documento Inteligente"
8. Submit pega valores de 'cliente-id-selecionado' e 'modelo-selecionado'
9. Envia para /api/documento/gerar-inteligente
10. Download do documento inicia
