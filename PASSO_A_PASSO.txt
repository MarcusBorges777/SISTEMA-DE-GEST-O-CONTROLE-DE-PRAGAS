========================================================================
              PASSO A PASSO - SISTEMA HIBRIDO JAVA + PYTHON
========================================================================

Você já instalou o Extension Pack for Java no VS Code!
Agora faltam apenas 2 passos:

========================================================================
                          PASSO 1: COMPILAR
========================================================================

Execute o arquivo:
   COMPILAR_BACKEND.bat

Ele vai:
- Encontrar o Maven do VS Code
- Compilar o backend Java
- Criar o arquivo .jar

Aguarde a mensagem: "BACKEND COMPILADO COM SUCESSO!"

========================================================================
                          PASSO 2: INICIAR
========================================================================

Execute o arquivo:
   INICIAR_COM_VSCODE.bat

Ele vai:
- Verificar Java e Python
- Encontrar o Maven do VS Code
- Iniciar o Backend Java (porta 8080)
- Iniciar o Frontend Python (porta 5000)
- Abrir o navegador automaticamente

========================================================================
                      ALTERNATIVA: VS CODE
========================================================================

Se preferir usar o VS Code diretamente:

1. Abra o VS Code na pasta "backend"
2. Abra o terminal (Ctrl + ')
3. Execute:
   mvn clean package -DskipTests

4. Depois execute:
   mvn spring-boot:run

5. Abra outro terminal e execute (na pasta raiz):
   python app.py

6. Acesse: http://localhost:5000

========================================================================
                          DÚVIDAS?
========================================================================

Se aparecer erro de "Maven não encontrado":
- Verifique se o Extension Pack for Java está instalado no VS Code
- Feche e abra o VS Code novamente
- Execute COMPILAR_BACKEND.bat

Se o backend não iniciar:
- Verifique se a porta 8080 está livre
- Veja os logs na janela do backend

Se o frontend não conectar ao backend:
- Aguarde 15 segundos após iniciar o backend
- Verifique se apareceu "Started Application" nos logs do backend
