=============================================================
LÓGICA DE CATEGORIZAÇÃO:
=============================================================

1. Sistema verifica o CNAE do cliente
2. Busca o CNAE nas categorias mapeadas (#0 a #11)
3. Se encontrar → usa a categoria correspondente
4. Se NÃO encontrar → usa #99 (Outros)
5. Se cliente NÃO tiver CNAE → usa #99 (Outros)

Exemplo de código:
categoria = obter_categoria_por_cnae('8122200')  # Retorna '#0'
categoria = obter_categoria_por_cnae('')          # Retorna None → vira '#99'
categoria = obter_categoria_por_cnae('9999999')   # Retorna None → vira '#99'

=============================================================
VANTAGENS DO #99:
=============================================================
✅ Identifica facilmente clientes sem categorização
✅ Não perde informação (sempre gera arquivo)
✅ Facilita organização e limpeza de dados
✅ Permite identificar CNAEs que precisam ser adicionados
✅ Número alto (#99) não conflita com categorias futuras

=============================================================
MAPEAMENTO DE CNAES:
=============================================================

Arquivo: categorias_cnae.py

Contém 11 categorias principais + categoria #99 automática

Total de CNAEs mapeados: ~50+ códigos
Cobertura: Principais setores estratégicos da prospecção

Para adicionar novos CNAEs:
1. Abra categorias_cnae.py
2. Localize a categoria desejada
3. Adicione o código CNAE na lista 'cnaes'
4. Reinicie o servidor
