✅ SCRIPTS ATUALIZADOS PARA MAVEN 3.9.12
═══════════════════════════════════════════════════════════════════════════

Todos os scripts foram atualizados para usar Maven 3.9.12 (a versao mais
recente disponivel).


🚀 OPCAO 1: INSTALACAO AUTOMATICA
═══════════════════════════════════════════════════════════════════════════

Execute:

  INSTALAR_MAVEN_SIMPLES.bat

O script vai tentar baixar automaticamente de 2 URLs:
  1. https://archive.apache.org/dist/maven/maven-3/3.9.12/binaries/apache-maven-3.9.12-bin.zip
  2. https://repo.maven.apache.org/maven2/org/apache/maven/apache-maven/3.9.12/apache-maven-3.9.12-bin.zip


📥 OPCAO 2: DOWNLOAD MANUAL
═══════════════════════════════════════════════════════════════════════════

Se a instalacao automatica falhar:

PASSO 1: Baixar
────────────────
Acesse uma destas URLs no navegador:

URL DIRETA (Recomendada):
https://archive.apache.org/dist/maven/maven-3/3.9.12/binaries/apache-maven-3.9.12-bin.zip

OU

URL ALTERNATIVA:
https://dlcdn.apache.org/maven/maven-3/3.9.12/binaries/apache-maven-3.9.12-bin.zip

OU

PAGINA OFICIAL:
https://maven.apache.org/download.cgi
  → Procure "Binary zip archive"
  → Clique em "apache-maven-3.9.12-bin.zip"


PASSO 2: Salvar
────────────────
Salve o arquivo como:

C:\Users\marcu\OneDrive\Área de Trabalho\sistema novo\SUGESTÃO CAIQUE\1\tools\maven.zip

IMPORTANTE:
  ✓ Nome do arquivo: maven.zip (exatamente assim, minusculas)
  ✓ Pasta: tools\
  ✓ Tamanho: ~9 MB (9.000.000 bytes)


PASSO 3: Instalar
────────────────
Execute:

  INSTALAR_MAVEN_SIMPLES.bat

O script vai:
  ✓ Detectar o arquivo maven.zip
  ✓ Pular o download
  ✓ Extrair para tools\apache-maven-3.9.12\
  ✓ Configurar tudo automaticamente


✅ VERIFICAR INSTALACAO
═══════════════════════════════════════════════════════════════════════════

Apos a instalacao, execute:

  INICIAR_SISTEMA_HIBRIDO.bat

O script vai detectar automaticamente o Maven 3.9.12 instalado localmente.


⚡ ALTERNATIVA: USAR SO PYTHON
═══════════════════════════════════════════════════════════════════════════

Se nao quiser instalar Maven agora, use:

  USAR_SO_PYTHON.bat

O sistema funciona perfeitamente so com Python!


📝 RESUMO DOS SCRIPTS
═══════════════════════════════════════════════════════════════════════════

INSTALAR_MAVEN_SIMPLES.bat     → Instala Maven 3.9.12 localmente
INICIAR_SISTEMA_HIBRIDO.bat    → Inicia sistema Python + Java
USAR_SO_PYTHON.bat              → Inicia sistema so Python
DIAGNOSTICO_MAVEN.bat           → Procura arquivo Maven no sistema
