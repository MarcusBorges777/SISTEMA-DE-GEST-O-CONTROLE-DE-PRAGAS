============================================================
  SISTEMA DE GESTAO DE DOCUMENTOS
  Com Autocomplete de CNPJs da Receita Federal
============================================================

INICIO RAPIDO
-------------

1. Execute: INICIAR_DASHBOARD.bat
2. Abra no navegador: http://localhost:5000
3. Pronto! O sistema está funcionando


FUNCIONALIDADES
---------------

✓ Gestao de Clientes
✓ Geracao de Documentos (Orcamentos, Contratos, Notas Fiscais)
✓ Upload e Extracao de PDFs
✓ Autocomplete de CNPJs da Receita Federal (500.000+ empresas)
  - Busca por CNPJ
  - Busca por Razao Social
  - Busca por Nome Fantasia
  - Busca por Logradouro
  - Busca por Bairro
  - Busca por CNAE
  - Performance: 6ms por busca


ENDPOINTS DISPONIVEIS
----------------------

Dashboard Principal:
http://localhost:5000

Clientes:
http://localhost:5000/clientes

Empresas:
http://localhost:5000/empresas

Documentos:
http://localhost:5000/documentos

API Autocomplete CNPJs:
http://localhost:5000/api/cnpj/autocomplete?campo=nome_fantasia&termo=Padaria&limit=10

ARQUIVOS ESSENCIAIS
-------------------

✓ app.py - Sistema principal Flask
✓ autocomplete_api.py - API de autocomplete de CNPJs
✓ db_manager.py - Gerenciador de banco de dados
✓ validators.py - Validadores de entrada
✓ document_learning.py - Sistema de aprendizagem de layouts
✓ document_extractor.py - Extrator de dados de PDFs
✓ templates/ - Frontend HTML
✓ modelos/ - Templates de documentos Word
✓ cnpj_filtrado.db - Banco de CNPJs da Receita Federal (500.000+ registros)
✓ gestao_documentos.db - Banco de dados principal


REQUISITOS
----------

- Python 3.7 ou superior
- Dependencias instaladas automaticamente no primeiro uso


TROUBLESHOOTING
---------------

Se o sistema nao iniciar:

1. Verifique se Python esta instalado:
   python --version

2. Instale dependencias manualmente:
   pip install flask flask-cors pdfplumber python-docx docxtpl python-dateutil google-generativeai python-dotenv requests

3. Verifique se os bancos de dados existem:
   - cnpj_filtrado.db
   - gestao_documentos.db

4. Execute novamente: INICIAR_DASHBOARD.bat
