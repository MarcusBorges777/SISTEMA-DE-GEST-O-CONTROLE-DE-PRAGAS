NOMENCLATURA DE ARQUIVOS GERADOS - FORMATO FINAL
=============================================================

FORMATO NOVO (CORRETO):
-----------------------
{NomeFantasiaOuRazaoSocial}_{NomeDoModelo}_{AAAAMMDD}.docx

EXEMPLOS:
---------
✓ DEDETIZADORA BORGES_LaudoPython2_20260109.docx
✓ MARIA APARECIDA DE OLIVEIRA_Laudo DDT sem ASSINATURA_20260109.docx
✓ RESTAURANTE XYZ_OrçamentoTemplate_20260109.docx
✓ EMPRESA ABC LTDA_ReciboTemplate_20260109.docx

COMPONENTES:
------------
1. {NomeFantasia ou RazaoSocial}
   - Usa Nome Fantasia se disponível
   - Se não, usa Razão Social
   - Se nenhum disponível, usa "Cliente"

2. {NomeDoModelo}
   - LaudoPython2
   - LaudoPythonCAIXA
   - OrçamentoTemplate
   - ReciboTemplate
   - Etc.

3. {AAAAMMDD}
   - Apenas a DATA (sem horário)
   - 20260109 = 09/01/2026
   - Formato: Ano (4 dígitos) + Mês (2 dígitos) + Dia (2 dígitos)

VANTAGENS:
----------
✓ Identifica facilmente o cliente
✓ Identifica o tipo de documento
✓ Data simples sem horário (evita nomes muito longos)
✓ Se gerar múltiplos documentos no mesmo dia, o sistema adiciona sufixo automático
✓ Caracteres especiais são substituídos por "_" automaticamente

EXEMPLOS REAIS:
---------------
Cliente: DEDETIZADORA BORGES
Modelo: LaudoPython2
Data: 09/01/2026
→ DEDETIZADORA BORGES_LaudoPython2_20260109.docx

Cliente: RESTAURANTE SABOR & CIA
Modelo: OrçamentoTemplate  
Data: 15/03/2026
→ RESTAURANTE SABOR _ CIA_OrçamentoTemplate_20260315.docx
(Note que "&" foi substituído por "_")

CÓDIGO:
-------
Localização: app.py linha 2019-2022

timestamp = datetime.now().strftime('%Y%m%d')
nome_cliente = cliente_dict.get('nome_fantasia') or cliente_dict.get('razao_social', 'Cliente')
nome_arquivo = f"{nome_cliente}_{modelo_path.stem}_{timestamp}.docx"
nome_arquivo = re.sub(r'[<>:"/\|?*]', '_', nome_arquivo)
